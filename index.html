Build it, code it, take it to a tournament.

The Mighty Bees build VEX IQ robots and compete in the REC Foundation's Engage league against schools across South Florida. Students design the robot, write the code that drives it, and run it in competition.

This year the team moved up from LEGO to VEX IQ. Leftover grant money covered getting us started. Everything past that is what we raise and what we earn, and the biggest thing on the list is a second robot so every student has a real job instead of a turn.
